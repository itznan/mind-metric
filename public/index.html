System Architecture & Operational Guide

Platform design, model switching, privacy guarantees, and usage instructions.

1. What StudentSuccess Does

StudentSuccess is a decision-support platform designed for academic advisors and retention committees. It identifies students at risk of dropout before they abandon their degrees, explains the underlying academic and financial signals, and prescribes concrete intervention recommendations.

2. Model Switching & Inference Modes

The platform supports three switchable modalities:

  • Ollama (Default Local Small Model): Runs open-weights models locally (e.g. qwen2.5:3b or llama3.2:3b) via http://localhost:11434. Completely on-premise, zero cloud API fees.
  • Claude (Anthropic API): Uses Anthropic's fast claude-haiku-5-5 model for zero-shot JSON inference. Configure via ANTHROPIC_API_KEY or directly in the sidebar.
  • Rule-Based Fallback (Offline): When no model is running or an API key is absent, the system automatically evaluates students using a deterministic scoring engine based on tuition arrears, unit completion ratios, and academic averages.

3. How to Install and Run Ollama

To use local zero-shot predictions on Linux or macOS:

# 1. Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 2. Download and run a small model
ollama run qwen2.5:3b

# 3. Start the StudentSuccess Node.js server
export MODEL_PROVIDER=ollama
npm start

4. Data Privacy & Ethical AI Standards

  • Zero PII Exposure: No student names, national identification numbers, or student IDs are sent to LLMs. Only numeric grades, unit tallies, and categorical status indicators are transmitted.
  • Human-in-the-Loop: Predictions are labeled as decision support and designed to assist human counselors in prioritizing outreach, not to automatically disqualify students.

5. Dataset Context & Limitations

The platform runs on the UCI Higher Education benchmark dataset (4,424 students from the Polytechnic Institute of Portalegre, Portugal). In real institutional deployments, predictive policies and models should be calibrated against the specific university's local demographic and grading parameters.
